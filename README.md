# hyttebok-media

Offentlige bilder til innlegg fra hyttebok.io på sosiale medier. Metricool henter bildene herfra.

## Ekte fotografier

`foto/2026-10/` inneholder to nettklare fotografier som grunnleggeren selv leverte 29.10.2026. Kopiene er kodet på nytt uten kamera-, tids- eller stedsmetadata. `hytte-ved-regnbue.jpg` brukes som hovedbilde på Hyttebok.io, og `hyttelandskap.jpg` i seksjonen om historien bak tjenesten. Bildene er ikke eksempelminner fra appen.
